# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-01

### Added

- Initial release of `plot-brain-surface` CLI and library
- Plot parcel weights on GIFTI cortical surfaces with Schaefer, HCP-MMP, and Brodmann atlases
- PNG and SVG output with optional per-hemisphere views
- Published on [crates.io](https://crates.io/crates/plot-brain-surface)
